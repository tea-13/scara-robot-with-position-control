## UI
Пользователь заполняет три поля координатами точки, которую хочет создать и нажимает кнопку **addTarget**. Если пользователь хочет удалить точку, то ему необходимо выбрать точку в **targetList** и нажать кнопку удаления точки **deleteTarget**.

## Применение градиентного спуска для решения обратной задачи кинематики
Градиентный спуск - это метод нахождения локального минимума функции. Функцию к которой будет применен метод назовем $\text{GetDistance}$, и она будет возвращать расстояние от последнего звена робота до точки. Сохраним в переменную $\text{distance1}$ начальное расстояние и сместимся на очень маленький угол $\Delta \theta = 0.01$ и снова измерим расстояние сохранив значение в переменную $\text{distance2}$. Вычисли производную по определению. Будем вычислять это значение для каждого звена и изменять угол поворота звена на величину $\phi$.

$$ \frac{d(\text{GetDistance})}{d \theta} = \frac{\text{distance2} - \text{distance1}}{\Delta \theta} $$

$$ \phi = - \alpha \cdot \frac{d(\text{GetDistance})}{d \theta} $$

где $\alpha$ — число равное скорости перемещения робота задается пользователем. Алгоритм продолжает работать до тех пор, пока функция $\text{GetDistance}$ не покажет значение меньше установленного переменной **threshold**.
